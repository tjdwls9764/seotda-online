# 2인용 온라인 섯다 (데모)

친구와 방 코드로 접속하는 모바일 웹 게임입니다. 실제 실시간 연결에는 Node.js 서버가 필요합니다.

## 로컬 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 열기

같은 Wi-Fi에서 다른 휴대폰으로 테스트하려면 컴퓨터의 로컬 IP 주소로 접속하세요. 인터넷을 통한 친구 초대에는 공개 호스팅이 필요합니다.

## 공개 배포
Node.js 웹 서비스를 지원하는 호스팅에 프로젝트 폴더를 배포하고 시작 명령을 `npm start`로 설정하세요. 서비스가 제공하는 HTTPS 주소를 친구에게 공유하면 됩니다. Socket.IO 연결을 지원하는 호스팅이어야 합니다.

## 주의
- 가상 칩 전용 데모이며 현금 베팅 기능은 없습니다.
- 방과 게임 상태는 서버 메모리에 저장되므로 서버가 재시작되면 사라집니다.
- 정식 공개 전에는 재접속 처리, 서버 권한 검증, 족보 규칙 전체 검수, 악용 방지 및 테스트를 추가하는 것이 좋습니다.
